سلسلة التأكيد — بلا تغيير

هذه هي الخاصية الأمنية التي قامت عليها كل مرحلة تالية دون أن تمسّها: الاقتراح يُسجَّل، ويُعرض بجسمه الحقيقي، ولا يُنفَّذ إلا برقم يكتبه المستخدم، ويُستهلك مرة واحدة.

  • القائمة البيضاء — خمسة أفعال فقط، وmethod والمسار من جدول ثابت لا من مخرجات النموذج.
  • تحقّق حتمي قبل إصدار الرقم: الحقول الإلزامية، صيغة الـUUID، فحص التكرار.
  • الاستهلاك مرة واحدة — /claim يتحقق ويحذف في خطوة واحدة، فلا رقم يُعاد ولا تأكيدان يفوزان.
  • عشر دقائق ثم يسقط الاقتراح، وأي اقتراح جديد يلغي سابقه.
